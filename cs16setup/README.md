# cs16db Demo Toolkit для CS 1.6 — «мега-сборка» записи демок

Набор превращает обе установки CS 1.6 (`D:\Counter-Strike Build 4554` и
`D:\CS 1.6 GoldClient`) в кино-машины: **одна кнопка в игре** — запись демки
с максимально точными данными для нашего конвейера (JSON → Blender/3ds Max/AE).

## Установка

```
cs16setup\install_demo_toolkit.bat          # обе установки (или путь к игре аргументом)
```

Что ставится в каждую `cstrike\`:
| Компонент | Назначение |
|---|---|
| `addons\metamod` (MetaMod-p v1.21p109) | платформа: подгрузка плагинов |
| `addons\amxmodx` (AMX Mod X 1.9 + cstrike-модуль) | любой AMXX-плагин из сообщества |
| `movie.cfg` | кино-набор: запись/камера/slow-mo/боты (клавиши F4–F11) |
| `autoexec.cfg` | автозагрузка `exec movie.cfg` при старте игры |
| `liblist.gam` → metamod.dll | цепочка запуска (создаётся `liblist.gam.bak`) |

Перед установкой всё, чего касается скрипт, копируется в
`addons_backup_<дата>_<время>`, `*.bak`. Откат: `cs16setup\restore_backup.bat`.

Проверка после запуска игры: в консоли `meta list` (список плагинов metamod) и
`amxx version` (версия AMX Mod X).

## Кнопки в игре (после установки)

| Клавиша | Действие |
|---|---|
| **F5** | боты-актёры: заморозить (`bot_stop 1`) / разморозить — постановка сцен, боты стоят на местах |
| **F6** | **запись демки** (цикл имён `rec1.dem` → `rec2.dem` → `rec3.dem`) |
| **F7** | сохранить демку |
| **F8** | камера от 3-го лица (кинематографичный план) / 1-е лицо |
| **F9** | slow-motion: x1 → x0.5 → x0.25 → x0.1 (демка записывается с замедлением!) |
| **F10** | чистый HUD вкл/выкл (для видео из игры; в демку HUD не пишется) |
| **F11** | скрыть/показать модель оружия |
| **F4** | `sv_restart 1` — чистый старт раунда (сброс таймкода перед записью) |

Хочешь свои клавиши/имена — правь `cs16setup\movie.cfg` (в игре `exec movie.cfg`).

## Гайд: как записать САМУЮ крутую демку

1. `sv_cheats 1` (одиночка/локальный сервер) — уже в movie.cfg.
2. Построй сцену: боты (`bot_add_t`, `bot_add_ct`), F5 — заморозь их на местах.
3. **F4** — чистый старт, **F6** — запись.
4. Снимай: F8 — план от 3-го лица, F9 — slow-mo для драматизма.
5. F7 — стоп. Демка лежит в `cstrike\*.dem`, **перетащи её на `make_replay.bat`**
   → через минуты `demos\replay_export.blend` со сценой, игроками, камерой и
   звуковыми маркерами.

### Команды, которые реально влияют на качество импорта

| Команда | Что даёт |
|---|---|
| `fps_max 300` | плавные позиции/углы в демке (больше сэмплов интерполяции) |
| `host_timescale 0.5` | slow-mo: события размазываются по большему числу тиков — в Blender всё автоматически растянуто по времени |
| `sv_restart 1` | чистая база времени — точные тики от нуля |
| `thirdperson; cam_idealdist 240` | кинематографичный обзор (в демку пишутся твои углы камеры) |
| `bot_stop 1` | заморозить ботов — постановка «живых декораций» |
| `record имя / stop` | классическая запись (F6/F7 дублируют) |

## Запись через HLTV — «про-режим» (полные данные матча)

Если демка пишется **после** мэйтча или матч идёт на сервере — подключи
локальный HLTV (есть в 4554): он запишет всех игроков без интерполяции
(протокол 48 — наш экстрактор читает его полностью).

```
1) Запусти игру и создай сервер (или подними выделенный).
2) cs16setup\record_hltv.bat [ip:порт]   (по умолчанию 127.0.0.1:27015)
3) HLTV пишет cs16_match.dem рядом с hltv.exe; закрой окно — запись готова.
```

## Про «карту глубины» и прочие данные — что есть у CS 1.6, а чего нет

Движок GoldSrc записывает в демку только игровые данные (тики, позиции,
углы, последовательности, звуки). **Того, что дают Source 1/2 — карты
глубины, motion vectors, отдельных AOV-проходов — у CS 1.6 нет в принципе.**
Но это и не нужно: у нас есть вся геометрия сцены, поэтому **глубина и всё
остальное рендерится в Blender**: Z-pass (глубина), vector-blur по движению,
маски, нормали — обычные render passes Cycles/Eevee по импортированной сцене.
Такой «depth» даже аккуратнее движкового (без шума, в любом разрешении).

## HD-контент (опционально, для более красивых моделей в Blender)

Наши модели/текстуры берутся из установки игры. Если поставить HD-паки
(фанатские, например с GameBanana: HD-модели игроков/оружия, текстуры 1024+),
конвейер автоматически декомпилирует **новые** модели и текстуры — сцена
в Blender сразу станет детальнее: `core\tools\mdl2smd.py` + `bsp_import.py`
работают с любыми HD-заменами. Просто положите новые `models\player\*.mdl`
и текстуры поверх установки и перезапустите `make_replay.bat`.

## Плагины AMX Mod X (платформа установлена — что докинуть)

- Демо-инструменты сообщества (auto-record, демо-менеджеры) — положить
  `.amxx` в `cstrike\addons\amxmodx\plugins\` и дописать имя в `plugins.ini`.
- Кино-команды сервера (`amx_slay`-подобные) — не нужны для записи, но
  пригодятся для координации «актёров» в мультиплеере.
- Исходники плагинов: `cstrike\addons\amxmodx\scripting\` (есть примеры).

## Состав репозитория cs16setup\

```
movie.cfg               кино-набор (F4–F11)
install_demo_toolkit.bat установка в обе сборки (скачивает MetaMod+AMXX с GitHub)
patch_liblist.ps1       патч liblist.gam на metamod
restore_backup.bat      откат бэкапов
record_hltv.bat         локальный HLTV-рекордер матча
hltv_movie.cfg          конфиг HLTV (join локального сервера + record)
```

Всё скачанное кэшируется в `cs16setup\downloads\`, распаковки — в `staging\`
(можно удалить, будет перекачано).
