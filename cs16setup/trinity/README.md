**Реальное состояние на 29.10.2026 (проверено):**

Что даёт: полностью переписанные world/model renderers, динамический
попиксельный свет для мира и повершинный для моделей, шейдерная вода,
мощная партикла, загрузка внешних TGA/DDS (4K), новый decal-систем и
клиентские скрипты.

## Как поставить бинари (когда скачаете архив)

1. Скачайте архив в `cs16setup\staging\trinity_dist\` (поддерживаются
   распакованная папка или `.7z`/`.zip` — установщик распакует сам при
   наличии 7-Zip или PowerShell).
2. `cs16setup\trinity\install_trinity.bat ["D:\path\to\CS 1.6"]` —
   копирование с бэкапом + `trinity_kino.cfg` + autoexec.
3. Откат: `restore_trinity.bat`.

## Интеграция с кино-набором

`trinity_kino.cfg` — пресет «кино» (точечные cvars уточняйте по доке
Trinity: trinity_menu). День/ночь без Trinity: плагин
`demo_toolkit_daynight.amxx` (`/day /dusk /night`).

## Сборка из исходников (для энтузиастов)

Репо автора — полноценный движок: компиляция cl_dll (HLSDK 4.x +
инструменты) и замена частей движка. Если решите собирать:
`core\extern\trinity-engine\readme\` — читать первым делом; обсуждения —
в треде TWHL и чатах сообществ GoldSrc-рейсинга. Это отдельный проект
(дни настройки), поэтому по умолчанию рекомендуем готовые бинари выше.
