# Trinity Engine для CS 1.6 (визуальный апгрейд движка)

> **Статус:** интеграционный модуль. Сам Trinity Engine НЕ распространяется
> на GitHub (проверено поиском: 0 публичных репозиториев) — релизы выходят
> на форуме **trinityengine.ru** (раздел «Скачать»). Этот каталог добавляет
> готовую установку/откат и стыковку с кино-набором cs16setup.

Что даёт движку (по словам авторов: попиксельный свет для мира,
повершинный для моделей, 4K-текстуры TGA/DDS, 3D-скайбоксы, шейдерная
вода, попиксельный туман, гамма-пресеты ночи):

- ночные/атмосферные сцены можно снимать сразу в игре (режим кино-записи F6),
- геометрия из Blender-ветки при этом остаётся эталонной (lightmap+текстуры),
- для глубины/матов по-прежнему используйте Blender/AE (в GoldSrc их нет).

## Установка

1. Скачайте последний релиз Trinity Engine с trinityengine.ru (архив metahook).
2. Распакуйте его в папку: `cs16setup\staging\trinity_dist\`
   (внутри должны лежать metahook.dll, trinity.dll и т.п.).
3. Запустите: `install_trinity.bat ["D:\path\to\CS 1.6"]` — файлы копируются
   в корень игры с бэкапом перезаписываемых. В инсталляцию добавляется
   `exec trinity_kino.cfg` в autoexec (см. ниже).
4. Откат: `restore_trinity.bat`.

## Интеграция с csvideo

`trinity_kino.cfg` — пресет «кино» (теплая гамма, лёгкий контраст; при
установке кладётся в `cstrike\cfg\`). Точные команды зависят от версии
Trinity — смотрите `trinity_menu`/README из архива; пресет содержит только
комментарии-заглушки, которые следует заполнить реальными cvars вашей
сборки. День/ночь без Trinity: плагин `demo_toolkit_daynight.amxx`
(уже установлен: `/day /dusk /night` или `dtk_time night`).

## Замечания

- Trinity работает только с движком 4554 (наш Build 4554 — ок);
- не совместим со старыми видеокартами/драйверами (нужен OpenGL 3+),
- анти-читы на онлайн-серверах: мод предназначен для локальных/кино-сессий.
