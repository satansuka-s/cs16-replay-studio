# CS_RenderHook для CS 1.6 (Metahook-плагин)

> **Статус:** интеграционный модуль. CS_RenderHook на GitHub не публикуется
> (проверено поиском: 0 репозиториев). Библиотека распространяется
> автором на игровых форумах (поиск по «CS_RenderHook»/XashHook-сообществам).
> Здесь — установка/откат и стыковка с кино-набором.

Эффекты (по описанию автора): SSAO (контактные тени), God Rays (объёмные
лучи), кинематографический bloom, пресеты цветокоррекции (LUT) —
«вшитый» аналог ReShade для движка (чище и быстрее, чем внешний оверхлей).

## Установка

1. Скачайте релиз CS_RenderHook у автора (форумный пост/страница ModDB).
2. Распакуйте в `cs16setup\staging\renderhook_dist\` (файлы вида
   metahook_*.dll, renderhook.dll и т.п.).
3. Запустите `install_renderhook.bat ["D:\path\to\CS 1.6"]` — файлы
   копируются в корень игры, перезаписываемые бэкапятся.
4. Откат: `restore_renderhook.bat`.

## Советы по кино

- SSAO/God Rays при записи демки (F6) записываются как есть — отличная
  база для рендера «как в игре»;
- для чистых пассов (без эффектов) временно отключите оверхлей
  (консольная команда автора, обычно `renderhook_enable 0`) — дальше
  геометрия/текстуры из нашего пайплайна в Blender.

## Ограничения

- Только локальные/кино-сессии (не для онлайн-серверов);
- требует GPU с поддержкой современных шейдеров (SM 3+);
- конфликты с другими Metahook-плагинами (Trinity) — ставьте по одному.
